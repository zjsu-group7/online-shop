## 二、如何运行

### 方式一：直接打开（10-10 骨架评审）

双击 `index.html` / `admin.html` 即可打开。后端未启动时页面自动进入
**静态骨架模式**：顶部显示灰色提示条，空态、表单、校验、交互全部可用，不会白屏报错。

### 方式二：随 Spring Boot 部署（10-13 联调）

把 `index.html`、`admin.html`、`css/`、`js/` 复制到后端仓库：

```
src/main/resources/static/
├── index.html
├── admin.html
├── css/
└── js/
```

启动后端（`mvn spring-boot:run`），访问 `http://localhost:8080/index.html`，
前端与接口同源，`fetch('/api/...')` 直连，无需任何代理配置。

### 方式三：接口冒烟测试（10-13 后，接口逐条自测）

```powershell
powershell -ExecutionPolicy Bypass -File test\api-smoke.ps1 `
  -BaseUrl http://localhost:8080 -Username seller -Password 12345678
```

脚本按「五步闭环」串行调用，并覆盖 401/400/404 分支，输出 PASS/FAIL 汇总，
失败时退出码为 1，可直接用于 10-14 联调自检。账号以后端配置为准。

## 三、五个演示动作（10-15 评审闭环）

| # | 动作 | 页面 | 接口 |
|---|------|------|------|
| 1 | 卖家登录 | admin.html | POST `/api/seller/login` |
| 2 | 发布商品 | admin.html | POST `/api/seller/products` |
| 3 | 买家看到商品 | index.html | GET `/api/product` |
| 4 | 提交意向、拿到口令码 | index.html | POST `/api/intents` |
| 5 | 卖家后台看到意向列表 | admin.html | GET `/api/seller/overview` |

演示技巧：admin.html 每 8 秒自动轮询总览；买家提交意向后切回卖家页，
意向 8 秒内自动出现（或点「刷新」立即拉取）。后台页内有可展开的「五步闭环」对照卡。

## 四、页面功能与接口对照

### index.html（买家端）

| 功能块 | 接口 | 说明 |
|--------|------|------|
| 商品展示 | GET `/api/product` | 名称/描述/图片/价格/状态徽标；无商品显示空态；FROZEN 显示"交易中"横幅 |
| 意向表单 | POST `/api/intents` | 姓名、电话去空格必填校验；400 时 Toast 显示后端 message 并自动刷新商品 |
| 口令码展示 | — | 提交成功后大字号展示 8 位码 + 一键复制 + "仅此一次"警示 |
| 凭码查询 | GET `/api/intents/{code}` | 客户端先按格式校验（8 位、剔除 I/O/0/1）；404 显示"无效或已失效" |

### admin.html（卖家后台）

| 功能块 | 接口 | 说明 |
|--------|------|------|
| 登录 | POST `/api/seller/login` | token 存 localStorage；401 显示"用户名或密码错误" |
| 总览 | GET `/api/seller/overview` | 当前商品卡 + 意向队列表（位次/姓名/电话/状态/时间）+ canPublish |
| 发布商品 | POST `/api/seller/products` | 名称≤100、描述≤2000、价格>0 两位小数、图片 JPG/PNG≤5MB 转 base64；不传图由后端补占位图 |
| 意向列表 | GET `/api/seller/overview` | 按位次正序；**不展示口令码**（接口设计约定，保护买家） |
| 退出登录 | POST `/api/seller/logout` | 清除本地 token；任何 401 自动跳回登录页 |

## 七、约定备忘

1. 统一响应体 `{ code, message, data }`，前端已做包装/不包装两种格式兼容；
2. 卖家鉴权头 `X-Token`；重新登录会使旧 token 失效（前端 401 自动回登录页）;
3. 口令码 8 位大写字母数字（剔除 I/O/0/1），**仅提交时返回一次**，前端不持久化；
4. 买家无账号体系，凭口令码查询/修改/撤销意向；
5. 图片：发布时传 `data:image/(jpeg|png);base64,...`，展示时兼容 dataURL / 绝对地址 / `/uploads/{file}` 文件名三种形态。
