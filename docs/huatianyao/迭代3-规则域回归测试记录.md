## 六、回归中发现并修复的缺陷

**F-1｜存量商品 stock 为 NULL 时成交直接 500（NPE）**
- 现象：迭代 1 存量数据无 stock 值；合并统一为 `Integer stock` 后（schema `stock INT` 可空），`markResult` 拆箱 `getStock() <= 0` 抛 NPE。
- 修复：`Product.stockOrZero()`（NULL 视为 0），四处读取点统一走该方法；`deductOneStock` 与 `ProductView` 同步兜底。
- 回归验证：TC-S20（409 拒绝 → 补货 → 正常成交）。
